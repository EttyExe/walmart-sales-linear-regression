# Walmart Weekly Sales Prediction Using Linear Regression

## About the Project

This is a beginner-friendly Machine Learning project that uses the Walmart sales dataset to explore and predict weekly sales using Linear Regression.

The project focuses on understanding data preprocessing, implementing Linear Regression using NumPy, and evaluating model performance.

## Objectives

- Explore the dataset using NumPy.
- Check and handle missing values.
- Detect and handle outliers using the IQR method.
- Apply categorical encoding, Min-Max Scaling, and Standardization.
- Split the dataset into training and testing sets.
- Implement Linear Regression using the Normal Equation and Batch Gradient Descent.
- Evaluate predictions using MAE, MSE, RMSE, and R².
- Verify the implementation using Scikit-learn.

## Tools and Libraries

- Python
- NumPy
- Pandas (for loading the dataset)
- Matplotlib
- Scikit-learn (for model verification)
- Google Colab

## Dataset

The project uses a Walmart weekly sales dataset containing sales information and related features, such as store, department, temperature, fuel price, markdowns, and unemployment.

The target variable is `Weekly_Sales`.

**Note:** The dataset file is not included in this README. Add the dataset to the repository only if you have permission to share it.

## Methods Used

1. Data exploration
2. Data preprocessing
3. Feature scaling
4. Train-test splitting
5. Linear Regression using the Normal Equation
6. Batch Gradient Descent
